// rules
do
─ inherit color via currentColor — never hard-code stroke fills.
─ keep stroke 1.5px at 16-20px sizes. scale stroke proportionally above 24px.
─ pair an icon with text in dense UI — bare icons need tooltips.
─ accent green is reserved for active / live / "you" states.

don't
─ use lucide's filled variants. ever.
─ mix icon sets — lucide only.
─ use emoji. none. not even a 🎉.
─ rotate or flip icons that have intrinsic direction.
─ apply gradients or shadows to icons.
